## Featured projects

### ⚽ Football Transfer Market Analysis

**How do transfer fees and buying patterns differ across clubs, leagues, and positions?**

An Excel-led analytics project connecting a documented workbook to a Python pipeline, SQL queries, and a native Power BI report project. The summer snapshot includes **1,493 transfer records**, with fee disclosure and currency differences handled explicitly.

- **Analysis:** league arrivals, club rankings, reported fees, announcement timing, and exploratory valuation gaps.
- **Deliverables:** Excel workbook, SQLite database, SQL results, Power BI project, and an interactive transfer ratings site.
- **Quality:** documented methodology, reconciliation checks, and automated pipeline validation. Power BI Desktop validation remains in progress.

**Tools:** Excel · Python · SQL / SQLite · Power Query · DAX · Power BI

[Explore the repository →](https://github.com/CopiousHighlights/football-transfer-market-analysis) · [View the interactive site →](https://football-transfer-analytics-trevor.trevorcoit781.chatgpt.site/)

### 🥊 UFC Matchups

**A fight-card comparison desk for researching matchups and recording breakdowns.**

A browser-based tool that brings fighter profiles, tale-of-the-tape comparisons, recent fights, and personal picks into one recording-friendly interface. The documented event snapshot covers **12 bouts and 24 fighter profiles**.

- **Comparisons:** measurements, source-listed performance metrics, and recent fight history.
- **Interaction:** card navigation, personal predictions, saved notes, and JSON export.
- **Design:** responsive layouts and a broadcast-style presentation for OBS recording.
- **Data:** documented source snapshots with explicit handling of missing statistics.

**Tools:** HTML · CSS · JavaScript · Python · JSON

[Explore the repository →](https://github.com/CopiousHighlights/UFC-Matchups)
