## Analytics projects

### Football Transfer Market Analysis

**Exploring transfer fees, buying patterns, and player valuations.**

An Excel-led project connecting a documented workbook to Python processing, SQLite queries, and a native Power BI report project. The summer snapshot contains **1,493 transfer records**.

- **Work:** compare league arrivals, club activity, reported fees, and announcement timing.
- **Deliverables:** Excel workbook, SQL queries and results, SQLite database, Power BI project, and an interactive transfer ratings site.
- **Methods:** preserve missing fees, distinguish currencies, document sources, and reconcile outputs. Power BI Desktop validation remains pending; valuation ratings are exploratory.

**Tools:** Excel · Python · SQL / SQLite · Power Query · DAX · Power BI

[Explore the repository →](https://github.com/CopiousHighlights/football-transfer-market-analysis) · [Open the interactive site →](https://football-transfer-analytics-trevor.trevorcoit781.chatgpt.site/)

### UFC Matchups

**A research and recording desk for sports breakdowns.**

A browser-based tool connecting fighter profiles, tale-of-the-tape comparisons, recent fights, and personal predictions in a broadcast-style interface. The documented event snapshot covers **12 bouts and 24 fighter profiles**.

- Compare fighters and navigate a complete event card.
- Save personal notes and predictions locally, with JSON export.
- Use responsive layouts designed around OBS recording.
- Explore a documented source snapshot with explicit handling of missing statistics.

**Tools:** HTML · CSS · JavaScript · Python · JSON

[Explore the repository →](https://github.com/CopiousHighlights/UFC-Matchups)
